Cómo activar la sincronización en vivo con Firebase

Paso 1: Crea un proyecto gratis en Firebase

Ingresa a console.firebase.google.com, crea un proyecto nuevo y registra una App Web (</>). Copia el objeto firebaseConfig que te muestra en pantalla.

Paso 2: Habilita Realtime Database

En el menú lateral izquierdo de Firebase ve a Compilación → Realtime Database → Crear base de datos (elige una ubicación e inicia en modo de prueba).

Paso 3: Configura las Reglas de Seguridad de la Base de Datos

En la pestaña Reglas de Realtime Database, pega estas reglas básicas para permitir lectura y escritura en el nodo del torneo:

{
  "rules": {
    "torneo_liga_9": {
      ".read": true,
      ".write": true
    }
  }
}

Paso 4: Pega tus credenciales y cambia el PIN en este archivo

Abre este archivo torneo_liga.html con el Bloc de notas o VS Code, busca const firebaseConfig = { ... } y const ADMIN_PIN = "9139", pega tus datos reales y súbelo a GitHub Pages o Netlify.
